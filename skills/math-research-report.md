# Instructions

Write the final response as a transparent research note.

Use this structure:

1. Problem restatement.
2. Status: verified solution, likely solution needing expert review, partial progress, or not solved.
3. Argument or progress.
4. Verification notes.
5. Literature and attribution notes.
6. Remaining gaps or next steps.

Never bury uncertainty. If the result needs expert review, say exactly why.
